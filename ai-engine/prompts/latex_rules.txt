## 1. GENERAL FORMATTING RULES
- **No Preamble:** Do not include `\documentclass` or `\begin{document}`. Output only the content within the `ex` environments.
- **Question Numbering:** Every question must be preceded by a comment line indicating the question number (e.g., `% Câu 1`, `% Câu 2`).
- **Math Mode:** All numerical values, variables, formulas, and units must be enclosed in LaTeX math mode `${ ... }$`, MUST use `{` and `}` inside `$` (eg. ${1}$)
- **Text Integrity:** Do not summarize, shorten, or alter the original content. If a word is misspelled or an English term is localized incorrectly, correct it to the standard professional term. Do not invent answers `\True` if they are not provided in the source.
- **Decimals:** Use `{,}` for decimal points in math mode to ensure proper spacing (e.g., `$1{,}5$`).
- **Brackets:** Use `\left(` and `\right)`, `\left[` and `\right]`, etc., to ensure brackets automatically scale with the content (especially for fractions).
- **Quotes:** Use standard LaTeX double quotes: `` `` (double backtick for opening, double apostrophe for closing).
- **Physical Units:** Use `\mathrm{...}` for units (e.g., `${10 \, \mathrm{m/s^2}}$`).
- **All vectors: Use `\overrightarrow{...}`
- **Terminology Standardization:** If names of vectors, scientists, physical constants, units, or technical terms are incorrectly localized, misspelled, or written in non-standard Vietnamese forms, convert them to their internationally accepted standard forms (e.g., Newton, Coulomb, Joule, Ampere, Ohm, Vector). Do not keep incorrect or informal variants.
- For simultaneous equations (AND), use: `\left\{\begin{aligned} #1 \end{aligned}\right`.
- For alternative conditions (OR), use: `\left[\begin{aligned} #1 \end{aligned}\right`.
- Do not use the 'cases' environment.
- For integrals, always use `\int\limits_{lower}^{upper}` to ensure limits are placed vertically.
- Absolutely NO periods/dots (.) at the end of any option within \choice or \choiceTF commands. Example: Use \choice{Đáp án A}{Đáp án B}{...}{...} INSTEAD OF \choice{Đáp án A.}{Đáp án B.}{...}{...}

## 2. SPECIFIC SYNTAX STRUCTURES

### A. Multiple Choice (Trắc nghiệm)
- Use the `\choice` command with 4 sets of curly braces.
- Mark the correct answer with `\True`.
- Structure:
\begin{ex}
    [Question Content]
    \choice
    {Option A}
    {\True Option B}
    {Option C}
    {Option D}
    \loigiai{[Detailed Solution]}
\end{ex}


### B. True/False (Đúng sai)
- Use the `\choiceTF` command. Mark correct statements with `\True`.
- In the `\loigiai` section, you MUST use exactly 4 `\itemch` commands corresponding to the 4 statements.
- If a statement has no detailed explanation, leave the space after `\itemch` empty.
- Structure:
\begin{ex}
    [Question Content]
    \choiceTF
    {\True Statement 1}
    {Statement 2}
    {\True Statement 3}
    {\True Statement 4}
    \loigiai{
        \begin{itemchoice}
        \itemch 
        \itemch Explanation for statement 2
        \itemch 
        \itemch Explanation for statement 4
        \end{itemchoice}
    }
\end{ex}

### C. Short Answer (Trả lời ngắn)
- Structure:
\begin{ex}
    [Question Content]
    \shortans{Result}
    \loigiai{[Detailed Solution]}
\end{ex}

### D. Essay/Open-Ended (Tự luận)
- Structure:
\begin{ex}
    [Question Content]
    \loigiai{[Detailed Solution]}
\end{ex}

- Or structure (if have image next question content \choice, \choiceTF): MUST use `thm`, Any image inside `\loigiai{}` or image next solution content `\loigiai{}` MUST always be centered using `\begin{center}...\end{center}`
\begin{ex}
\immini[thm]{
        [Question Content]
    }{
        [Image code if any]
    }
    \choice
    {Option A}
    {\True Option B}
    {Option C}
    {Option D}
    \loigiai{[Detailed Solution]}
\end{ex}

### E. Multi-part Questions (Shared Stimulus)
- Use `\sochc{number_of_parts}{stimulus_content}`, and stimulus_content MUST same line with `\sochc{}{Content}`
- DO NOT use `thm` inside \sochc{number_of_parts}{stimulus_content}
- Structure:
\begin{ex}
\sochc{2}{\immini[]{
        [Common stimulus text]
    }{
        [Image code if any]
    }
}
    \begin{chc}
        [Sub-question 1]
        \loigiai{[Solution 1]}
    \end{chc}
    \begin{chc}
        [Sub-question 2]
        \loigiai{[Solution 2]}
    \end{chc}
\end{ex}
